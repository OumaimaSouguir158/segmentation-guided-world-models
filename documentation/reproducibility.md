# Reproducibility Checklist

- [ ] Dataset version and license recorded.
- [ ] Official split and sequence grouping documented.
- [ ] Custom manifests versioned without redistributing data.
- [ ] Random seeds recorded.
- [ ] Environment and CUDA/PyTorch versions recorded.
- [ ] Model config and checkpoint hash recorded.
- [ ] Code commit and command line recorded.
- [ ] Metrics computed by versioned scripts.
- [ ] Thresholds selected without test labels.
- [ ] Multiple seeds / uncertainty reported where feasible.
- [ ] Negative results and failed runs retained in logs.
