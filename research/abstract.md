# Abstract

Visual perception systems often encounter distribution shifts caused by weather, illumination, geography, camera changes, seasonal variation, or sensor degradation. Semantic segmentation offers structured information about scene content, while predictive visual models can encode temporal regularities and detect unexpected observations. This project investigates whether combining these signals can improve drift detection and support safer test-time adaptation (TTA).

The proposed framework contains (i) a semantic segmentation encoder and prediction head, (ii) a compact temporal latent predictor, (iii) a multi-signal drift monitor, and (iv) a confidence-gated adaptation controller. Candidate drift evidence includes changes in latent feature statistics, semantic class proportions and confidence, and prediction residuals between observed and predicted latent states. Adaptation is restricted to selected normalization parameters or lightweight adapters, and is enabled only when confidence and drift criteria satisfy pre-defined safeguards.

Experiments will use urban-scene datasets with complementary shift properties, beginning with Cityscapes and ACDC and expanding to BDD100K, Mapillary Vistas, and synthetic-to-real data if compute and licensing permit. Evaluation will report segmentation quality, drift-detection AUROC/AUPR/FPR, calibration, temporal stability, adaptation benefit, compute cost, and failure cases. The project tests the hypothesis that semantic and temporal cues provide complementary drift evidence; it does not assume this hypothesis is true.
