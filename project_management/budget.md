# Six-Month Budget Framework

This is a planning framework, not a quote or confirmed funding request. Prices must be replaced with dated quotations before submission.

| Cost category | Planned approach | Budget status |
|---|---|---|
| Researcher time/stipend | Six-month full-time or part-time research effort | To be proposed to funder |
| Compute/GPU | Free/available GPU first; paid cloud only if justified | Quote required |
| Storage/backup | External storage for checkpoints and logs; no raw dataset redistribution | Quote required |
| Connectivity | Existing internet access | Confirm actual incremental cost |
| Publication | Prefer no-fee venues/preprints; APC only if approved | Not committed |
| Contingency | Reserve for compute/storage variability | To be estimated |

Do not invent a total. Attach provider quotations and distinguish cash costs from in-kind resources. Confirm whether the funder permits researcher compensation, equipment and indirect costs.
