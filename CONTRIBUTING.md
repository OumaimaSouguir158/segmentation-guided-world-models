# Contributing

Contributions should be reproducible and scientifically traceable.

1. Open an issue describing the research question or defect.
2. Do not upload dataset files, credentials, personal data, or unlicensed material.
3. Add tests for code changes and record environment/configuration changes.
4. Separate measured findings from hypotheses.
5. For experiment results, report dataset split, shift severity, seed, model checkpoint, metric implementation, hardware and runtime.
6. Avoid claiming superiority from a single seed or cherry-picked condition.
