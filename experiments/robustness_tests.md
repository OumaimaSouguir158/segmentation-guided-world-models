# Robustness and Failure Tests

- abrupt vs gradual shift;
- recurring shift and return to source;
- mixed conditions in one stream;
- low-confidence and high-entropy batches;
- rare-class prevalence changes;
- temporal discontinuity / scene cut;
- noisy pseudo-labels;
- limited update budget;
- false alarms under in-domain novelty.

Record failures and rollback events, not only average scores.
