# Cityscapes Dataset Card

Official project: https://www.cityscapes-dataset.com/  
Original paper: https://doi.org/10.1109/CVPR.2016.350

- Purpose: urban-scene understanding and semantic segmentation.
- Common fine-annotation split: 2,975 train, 500 validation, 1,525 test images; test annotations are not publicly available in the same way as train/validation.
- Use in this project: source training and in-domain calibration/validation, subject to official split rules.
- Access: registration and dataset terms apply.
- Caution: respect city/sequence grouping and official evaluation rules. Verify counts and current package details from the official site.
