# ACDC Dataset Card

Official project: https://acdc.vision.ee.ethz.ch/

- Purpose: adverse-condition semantic perception.
- Conditions: fog, nighttime, rain and snow.
- Scale: 4,006 adverse-condition images, evenly distributed across the four conditions, according to the official project description.
- Annotations: pixel-level panoptic semantic annotations, corresponding normal-condition images and masks distinguishing clear/uncertain regions.
- Use in this project: shifted evaluation and paired-condition analysis.
- Access/license: the official site states free use for non-commercial purposes subject to its license terms. Read and accept the current terms before downloading.
- Caution: paired clear/adverse images must not be treated as independent samples when estimating uncertainty.
