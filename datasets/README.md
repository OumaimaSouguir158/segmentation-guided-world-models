# Dataset and Benchmark Plan

## Primary starting pair
- **Cityscapes:** source-domain urban-scene segmentation baseline. Access requires registration and acceptance of terms.
- **ACDC:** adverse conditions (fog, night, rain, snow) with corresponding clear-condition images and pixel-level annotations. Use the official terms; do not redistribute archives.

## Expansion candidates
- **BDD100K:** broad driving conditions and tasks; review task-specific annotation availability and terms.
- **Mapillary Vistas:** geographically diverse street scenes; research-edition access and license conditions apply.
- **GTA5 / SYNTHIA:** synthetic source domains for synthetic-to-real adaptation, subject to dataset-specific terms.

Start with one segmentation architecture and a manageable subset/resolution. Confirm storage and GPU memory before full-resolution training.
